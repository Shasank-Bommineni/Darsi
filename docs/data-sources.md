# Data sources

Every byte of geographic data in this project, where it came from, and the
licence it carries. If something is not listed here, it is generated by code in
this repository and is original work.

Place: **Darsi, Prakasam district, Andhra Pradesh, India — PIN 523247**
Anchor used by the pipeline: **15.7694505 N, 79.6776541 E**
High-quality sector: **8.4 km × 8.4 km** centred on that anchor
(`--half-km 4.2`; the DEM window is fetched slightly wider, at 5.2 km, so the
terrain has no edge artefacts).

## 1. OpenStreetMap — roads, buildings, water, place names, POIs

| | |
|---|---|
| Source | Overpass API (`overpass.kumi.systems`, after `overpass-api.de` returned HTTP 504) |
| Query window | south 15.731721, west 79.638449, north 15.807180, east 79.716859 |
| Retrieved | 2 October 2026, via the `data.yml` GitHub Actions workflow |
| Elements | 606 |
| Raw file | `data/osm/darsi_osm.json` (500,929 bytes, committed) |
| Licence | **ODbL 1.0** — © OpenStreetMap contributors |
| Attribution | Shown on the game's boot screen and in this file |

Fetched by `tools/fetch_osm.py`. The script validates the element count
(`MIN_ELEMENTS = 400`) because Overpass mirrors are known to answer HTTP 200
with an empty `elements` array; an empty answer is treated as a failure and the
next mirror is tried.

What is used from it:

- **1,040 road edges / 870 nodes / 137.55 km** of carriageway, including the
  road names (`Podili - Vinukonda Road`, `MDR087`, …), surface tags, `oneway`,
  bridges and layer tags.
- **142 building footprints** traced by OSM mappers, used verbatim.
- **24 landuse / natural areas** (8 of them water) and 3 waterways.
- **45 POIs** — hospitals, fuel stations, schools, a college, a police station,
  a theatre, two bus stations, one place of worship, and 12 named settlements.
- **17 railway ways** and **3 power lines**.

`out geom` returns whole ways, including geometry far outside the bounding box,
so every polyline is clipped to the world square before use. Without the clip
the network measures 119 km of nonsense instead of 137.55 km of Darsi.

## 2. Elevation — NASA SRTM via AWS Terrain Tiles

| | |
|---|---|
| Source | AWS Open Data *Terrain Tiles* (`elevation-tiles-prod`), terrarium encoding |
| Underlying data | **NASA SRTM 1-arcsec** over India (~30 m posting) |
| Tiles | zoom 13, x 5908–5910, y 3731–3733 (3 × 3) |
| Mosaic bounds | N 15.834536, W 79.628906, S 15.707663, E 79.760742 |
| Resolution used | 768 × 768 samples over the DEM window |
| Measured range | 57 m – 357 m (raw tiles); 74.1 m – 317.7 m inside the game world |
| Licence | Public domain (NASA SRTM); AWS Open Data programme, no restrictions |

Fetched by `tools/fetch_dem.py`. Ground elevation at the anchor is **≈112 m**,
which matches published figures for Darsi. The terrain in the game is this
measurement, resampled to a 769² grid at 10.94 m spacing — it is not noise and
it is not flat.

## 3. Everything else is generated

No third-party textures, models, sounds or imagery are used anywhere.

| Asset class | How it is made |
|---|---|
| Textures | Procedural, drawn into `CanvasTexture` at load time — `src/render/textures.js` |
| Buildings | Generated geometry from footprints + category — `src/world/buildingBuilder.js` |
| Road surfaces | Generated ribbons with potholes/patches — `src/world/roadBuilder.js` |
| Motorcycle | Original design, built from primitives — `src/bike/bikeModel.js` |
| Rider, traffic, pedestrians | Original geometry — `src/bike/rider.js`, `src/ai/*` |
| Sky | Original GLSL shader — `src/render/sky.js` |
| Audio | Synthesised live with WebAudio oscillators and noise — `src/audio/audio.js` |

## 4. Legal position

**Used, and permitted:**

- OpenStreetMap data under ODbL, with attribution (above and in-game).
- NASA SRTM elevation, public domain.
- Our own procedural geometry, textures and audio.

**Deliberately not used:**

- Google, Apple or Bing imagery, Street View, or any of their 3D/mesh data —
  not as textures, not traced, not redistributed.
- Any proprietary 3D model, photograph or sound library.

Commercial satellite or street-level imagery may only ever be consulted as
*visual reference by a human*, in the way an artist looks at a photograph; no
pixel of it enters this repository. Nothing in the project is presented as
official, surveyed or government data.

## 5. Reproducing the data

Network access from the build sandbox is restricted, so acquisition runs in
GitHub Actions and the results are committed:

```
.github/workflows/data.yml     # triggered by pushes to the fetch scripts
  └── tools/fetch_osm.py       # -> data/osm/darsi_osm.json
  └── tools/fetch_dem.py       # -> data/dem/*
  └── tees its output into data/acquire.log   (the only way to read CI output here)
```

Then, locally:

```
python3 tools/build_world.py      # -> game/public/world/  (~5.3 MB, 4 s)
cd game && npm install && npm run dev
```

`tools/build_world.py` is deterministic: the same inputs always produce exactly
the same world, because every random decision is seeded from a stable hash of
the feature's identity rather than from a global RNG.
