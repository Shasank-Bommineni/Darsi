# Android build checklist

This checkout is a Godot 4 project and includes an Android export preset. The repository intentionally contains no signing keys.

1. Install Godot 4.3+ and the Android export templates.
2. Import the project, run the desktop prototype, and review the map provenance screen.
3. In **Project > Export**, select **Darsi Android** and configure the local debug keystore for development. For release, use a private release keystore outside the repository.
4. Export an APK for a device test. Landscape orientation is configured; touch targets are generated by `scripts/main.gd`.
5. Profile on a mid-range Android phone before adding content. Start with Compatibility renderer, 30 FPS, and low/medium settings; only enable 60 FPS after measuring frame time.

The first slice does not yet include a shipping asset bundle, online services, or a signed artifact. The next performance pass should add graphics settings, sector activation, object pooling for traffic/NPCs, texture compression, and a device test matrix.
